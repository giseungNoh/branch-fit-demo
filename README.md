# BranchFit Demo

AI 기반 은행 점포 입지·통폐합 의사결정 지원 플랫폼 데모입니다.

## 포함 기능
- 서울 IBK 점포 운영현황 탐색
- 통·폐합 후보 점포 탐색
- 사전영향평가 워크스페이스
- 대체수단 시뮬레이션
- 고객·지역 의견수렴
- AI 의사결정자 리포트
- 사후영향평가
- 평가기준별 필수 데이터 정의서

## 원칙
- 공식 사전영향평가 기준과 BranchFit 자체 후보 탐색 기준을 구분합니다.
- 내부 데이터가 없으면 임의 추정하지 않고 UNKNOWN/추가 확인 필요로 처리합니다.
- AI는 설명·요약을 담당하며 최종 폐점 결정을 자동 수행하지 않습니다.
